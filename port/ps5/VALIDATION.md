# Проверки ICO PS5 — 29 октября 2026

## Подтверждено на Mac

- Upstream `b55a34f65adaee73b68362aab355b076feebf108`.
- 215 игровых C-файлов и таблицы скомпилированы Clang 18 для PS5.
- Vulkan-рендерер с 173 SPIR-V шейдерами, libmpeg2, libchdr, SDL3 3.4.18,
  DualSense, AudioOut и RADV слинкованы в один ELF.
- В ELF нет экспортов приложения; системные импорты разрешены по SDK stubs.
- FSELF `eboot.bin` и clean-room `libc.prx`: integrity valid.
- MkPFS 1.1.0 `--verify`: 0 ошибок. Обратная распаковка сверяется по полному
  набору имён, размерам и SHA-256 каждого файла (точное число — в квитанции).
- Исходный ISO не изменён. Импорт оригинальной PAL-версии принят штатным
  проверяющим кодом по ELF SHA-1 и манифесту DATA.DF. Альтернативные данные
  репака DATA.D2 исключены. `ico.o2r`: 872 910 607 байт.
- Загружены 75 строк таблиц, 29 657 записей, без пропущенных таблиц.
- Игра без графического окна отработала 300 Main ticks, 607 vsyncs,
  stage_no 1, завершилась штатно по лимиту. SPU2 обработал 486 238 кадров.
  Это проверяет загрузку и начальную симуляцию, не вывод изображения/звука.
- Тест управления использует настоящий виртуальный SDL-драйвер и подменённые
  scePad/sceUserService: 14 игровых кнопок, граничные значения стиков,
  триггеры, вибрация, сброс состояния после ошибки и повторное открытие.
- Тест звука использует настоящий SDL 3.4.18, его конвертер и звуковой поток,
  с подменённым AudioOut: float mono 44,1 кГц преобразуется в S16 stereo
  48 кГц, выдаются ненулевые кадры, закрытие занимает меньше секунды,
  проверяется отказ открытия. Блокирующий AudioOut вызывается в WaitDevice
  вне mutex SDL; начальный вариант в PlayDevice задерживал закрытие.
- Оба платформенных теста проходят за время менее секунды.

Логи и квитанции: `build/validation/`, `build/ps5/linked/`,
`dist/with-game/verification.json`. Квитанция — источник актуальных хешей
пакета, ELF и каждого включённого файла. `console_tested` намеренно false.

## Первая проверка на PS5

1. Установить `dist/ICO-PS5-PPSA99030-with-game.ffpfsc` через ShadowMountPlus
   либо скопировать папку `dist/with-game/PPSA99030/` в
   `/data/homebrew/PPSA99030/` и смонтировать её. Title ID PPSA99030.
2. Запустить плитку ICO. Зафиксировать, дошёл ли запуск до титульного меню,
   звук, изображение, работу ✕/○ и Options.
3. Начать новую игру, проверить движение, камеру, R1 и вибрацию.
4. Сделать и загрузить сохранение, перезапустить приложение.
5. Сохранить `/data/ico/PPSA99030/logs/ico-pc.log`, `.previous`, crash/report
   файлы и klog при падении. Не заменять пользовательскую папку при обновлении.

## Повторение платформенных тестов

Сначала сконфигурировать нативную для хоста статическую SDL из
`build/deps/sdl3` после `prepare-ps5-sdl.py`. Для этого не использовать PS5
CMake toolchain; отключить video/render/GPU и включить audio/joystick.
Затем:

```sh
cmake -S port/ps5/test -B build/validation/tests -G Ninja \
  -DSDL3_DIR="$PWD/build/validation/sdl3"
cmake --build build/validation/tests
ctest --test-dir build/validation/tests --output-on-failure
```

AudioOut и libScePad в тестах подменены. Эти тесты не заменяют проверку
железа, но выполняют настоящий SDL-код адаптеров.
